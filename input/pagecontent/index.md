### Scope

This guide describes **The Right Way To Exchange Health Data**. It has been written with care by people who
have seen the other ways.

It defines profiles, extensions, terminology, capability statements, operations, a questionnaire, logic,
test plans and an example scenario. Each artifact exists because, at some point, an implementation needed to
be told about it.

<div class="stu-note" markdown="1">
This is a synthetic guide. All systems, organisations and people in it are generic archetypes; any
resemblance to a real integration project is a sign of how universal the experience is.
</div>
