### A brief history of doing it wrong

Health data has been exchanged for as long as there has been health data. For most of that time it has been
exchanged on paper, then by fax, then as a PDF sent by fax, which combined the disadvantages of both.

The [interoperability maturity levels](CodeSystem-interop-maturity.html) record this progress. They are
cumulative: a system at the highest level retains the ability to fall back to any lower level, and usually
does so on the first day of production.

### Why another guide

Every guide is written to fix the problems left by the previous guide. This one is no exception. It differs
only in that it says so.

| Level | What it looks like | How it is described in the press release |
|---|---|---|
| Analog | A fax | Secure, point-to-point delivery |
| Digital | A CSV file | Structured data exchange |
| API | A FHIR server | FHIR-enabled |
